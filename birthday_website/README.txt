BIRTHDAY WEBSITE — QUICK START

1. Extract the ZIP file.
2. Open the birthday_website folder.
3. Double-click index.html to open it in your browser.
4. Edit the text in index.html and the reasons in script.js to make it personal.
5. Add your photos:
   - Put image files inside the assets folder.
   - Replace the photo-placeholder divs in index.html with:
     <img class="your-photo" src="assets/your-photo.jpg" alt="Our memory">
   - Add this CSS rule if needed:
     .your-photo { width:100%; height:210px; object-fit:cover; border-radius:12px; }

This project uses only HTML, CSS and JavaScript. Google Fonts requires an internet connection.
For publishing, you can use GitHub Pages or Netlify.
